# アイディアメモ：なかま そだて（仮）

> 状態：試作を公開（ぽぷら 1種類）　作成：2026-10-04

## コンセプト
毎日計算を解くと、たまごから生まれた「なかま」が育っていく。月末には旅立って、ずかんに載る。

- **目的は「継続」**。たくさん解いた日に一気に育つ形にはしない
- シール＝毎日のごほうび、なかま＝毎月のごほうび

## 決まったこと

| 項目 | 内容 |
|---|---|
| 育ち方 | 「めあて（10問）をクリアした日数」で育つ。問題数のボーナスはなし |
| 3日休んだとき | なかまが手紙を残していえでする。翌日に新しいたまごが届く |
| いえでした子 | ずかんに「いえでしちゃった」として薄く載る。もう一度会えるのは、別の月に同じ子が生まれたとき |
| なかまの種類 | 方向は決めずにバラバラ（動物・恐竜・空想の生きもの など） |
| 生まれるなかま | ランダム |
| 名前 | 付けられる。ひらがなのみ、5文字まで。いじわるな名前は付けられない |
| 絵 | 全身の絵。動きも付ける |

## 1か月の流れ

| 時期 | できごと |
|---|---|
| 月のはじめ（1日） | 新しいたまごが届く。生まれるまで、どのなかまかは分からない |
| 月のあいだ | めあてクリアの日数で育つ |
| 月末 | どこまで育っていても旅立つ。ずかんに「○○まで育った」と記録 |
| 3日休んだとき | いえで → 翌日に新しいたまご（その月の残りで育てる） |

## 育つ段階と日数（目安）

| 段階 | めあてクリアの日数 |
|---|---|
| たまご | 0日 |
| 赤ちゃん（生まれる） | 2日 |
| 子ども | 6日 |
| 青年／乙女 | 11日 |
| 大人 | 17日 |
| おとしより | 23日 |

- 月に23日で最後まで育つ（週1〜2日休んでも届く）
- 月の途中で始めた・いえでのあと新しいたまごが来た、などのときは、残り日数に合わせて必要日数を縮める
- 「青年」か「乙女」かは、なかまごとに決める

## 休んだ日の様子

| 休んだ日数 | 様子 |
|---|---|
| 1日 | 「さみしいな…」と言う |
| 2日 | しょんぼり顔。みー と ころ が「きょうは あいに いこう！」と声をかける |
| 3日 | 手紙を残していえで |

- おうちの方用の「おやすみ」登録（旅行など）があると安心。登録した日は休んだ日に数えない（要検討）

## 名前のルール
- ひらがなのみ（「ー」は可）、1〜5文字
- いじわるな言葉・悪口・下品な言葉は付けられない（禁止語リストで判定）
- 付けられないときは、みー と ころ が「ちがう なまえに しよう」とやさしく伝える
- 名前を付けなかったときは、種類の名前で呼ぶ

## 動き
- **いつも**：ゆっくり上下にゆれる（呼吸しているような動き）
- **正解したとき**：ぴょんと跳ねる。よろこびポーズの絵に切り替える
- **しょんぼりのとき**：小さく首をかしげる。しょんぼりの絵に切り替える
- **たまご**：ときどきゆれる。生まれる前日は大きくゆれる
- **段階が上がったとき**：光って大きくなる演出 → 新しい絵
- アプリ側の動き（CSS）と、絵の切り替えの組み合わせで作る

## 画面
- いろいろ もんだいの画面の上（「きょうの シール」の近く）に、今のなかまを小さく出す
- 段階が上がった日は「○○が 子どもに なったよ！」のお知らせ
- 「ずかん」画面に「なかま ずかん」を追加
  - 旅立った子：月ごと（例：10がつ ○○ おとしよりまで そだった）
  - いえでした子：薄く表示
  - まだ会っていない種類：影（シルエット）

## 保存
- 端末ごと（今の記録と同じ）。兄弟で端末を分ければ、それぞれ育つ

## 必要な絵（1種類あたり）
| 絵 | 枚数 |
|---|---|
| 成長の6段階（ふつうのポーズ） | 6 |
| 成長の6段階（よろこびポーズ） | 6（たまごは「ゆれている」絵） |
| しょんぼり（赤ちゃん〜おとしより） | 5 |
| 旅立ち（大人の姿でリュックを背負って手を振る） | 1 |

共通で、いえでの手紙の絵が1枚あるとよい。

## 最初のなかま案（5種類・方向はバラバラ）
1. **ぽぷら**：葉っぱの妖精（しょくぶつ系・乙女）
2. **ごろすけ**：小さな岩のかいじゅう（ちから系・青年）
3. **ふわりん**：雲のひつじ（そら系・乙女）
4. **ぴっか**：電気のひよこ（ひかり系・青年）
5. **ちゃぷ**：水のかめ（みず系・青年）

## MC（2026-10-04 追加）
- 12しゅるい すべてを「旅立ち」で集める（段階は問わない・いえでは数えない）と、MCを選べるようになる
- 生まれるなかまは、まだ集めていない種類から先に出る（12か月でそろう）
- MCのデータ（性格・語尾・場面ごとのセリフ）は `nakama/nakama.js` に1か所でまとめる
- なかま ずかんの表記：たびだったよ（○○で）／いえでしちゃったよ／いくせいちゅうだよ
- 12しゅるい集め終わったら、なかま そだては終わり（新しいたまごは届かない）。そのあとはMCとして一緒に勉強する
